# HR Analytics Dashboard | Power BI

## Project Overview
This project focuses on analyzing employee data using Power BI to gain insights into workforce distribution, employee demographics, and HR performance.

## Key KPIs
- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Employee Age

## Dashboard Features
- Employee distribution by department
- Gender-wise employee analysis
- Attrition analysis by department
- Employee demographics and age groups
- Job role and education analysis
- Interactive filters for exploring HR data

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset
The dataset contains employee-related information such as department, job role, age, gender, education, and attrition status.

## Objective
To help HR teams understand workforce trends, monitor employee attrition, and make data-driven decisions to improve employee retention and workforce planning.

## Key Learnings
- Data cleaning and transformation using Power Query
- Creating KPIs and measures using DAX
- Designing interactive dashboards in Power BI
- Analyzing HR metrics and presenting insights visually
